## 收录原则

- 保存结构化摘要、个人理解、实践启发和原始来源链接。
- 不镜像受版权保护的全文或原始图片；图片优先使用自制图表，第三方素材保留出处与许可信息。
- 对会持续更新的网页记录阅读日期，避免把当时版本误认为永久结论。

## 推荐阅读路径

1. 先读「一句话结论」和 SDLC 映射。
2. 再看「有效模式」和「边界」。
3. 最后把「可执行清单」转成团队实验或工程规范。
